# Suruh Lead Radar

إضافة WordPress لمتابعة العملاء المحتملين وإدارة بياناتهم من داخل لوحة التحكم.

## المزايا

- تسجيل العملاء المحتملين ومتابعة بيانات التواصل.
- عرض وإدارة العملاء من لوحة تحكم WordPress.
- تتبع تفاعل الزوار عبر ملفات JavaScript المرفقة.
- تكاملات وواجهات REST قابلة للتوسعة.
- صفحة إلغاء تثبيت لتنظيف بيانات الإضافة عند الحاجة.

## التثبيت

1. نزّل المستودع أو اضغطه في ملف ZIP.
2. ارفع مجلد `suruh-lead-radar` إلى مجلد `wp-content/plugins/`.
3. فعّل الإضافة من صفحة **الإضافات** في لوحة تحكم WordPress.

## المتطلبات

- WordPress حديث.
- PHP متوافق مع إصدار WordPress المستخدم.

## البنية

- `suruh-lead-radar.php`: الملف الرئيسي للإضافة.
- `includes/`: منطق الإدارة وقاعدة البيانات والواجهات والتكاملات.
- `assets/`: ملفات CSS وJavaScript.
- `uninstall.php`: تنظيف بيانات الإضافة عند إلغاء تثبيتها.

## الترخيص

هذا المشروع مخصص للاستخدام مع موقع WordPress الخاص بك.
